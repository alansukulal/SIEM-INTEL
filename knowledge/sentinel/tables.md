# Microsoft Sentinel Tables

## SigninLogs

SigninLogs contains Microsoft Entra ID sign-in and authentication events.

Important columns:

- TimeGenerated
- UserPrincipalName
- ResultType
- IPAddress
- Location
- AppDisplayName

Use SigninLogs when investigating user authentication activity, failed sign-ins, successful sign-ins, suspicious IP addresses, applications, or authentication failures.

---

## Heartbeat

Heartbeat contains heartbeat information from agents connected to Microsoft Sentinel.

Important columns:

- TimeGenerated
- Computer
- Category
- Version

Use Heartbeat when investigating whether connected agents are sending heartbeat information to Microsoft Sentinel.

---

## SecurityEvent

SecurityEvent contains Windows security events collected from Windows machines.

Important columns:

- TimeGenerated
- Computer
- Account
- EventID
- Activity
- IpAddress

Use SecurityEvent when investigating Windows security activity, account activity, Windows event IDs, and events generated by Windows machines.
